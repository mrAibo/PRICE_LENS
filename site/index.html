Early MVP · independent project

Compare the product, not just the words.

PriceLens is a browser-extension project for safer product and price comparison. It starts from the exact listing a user is viewing, separates condition and shipping uncertainty, and refuses to call a similar-looking variant the same product without enough evidence.

User-triggered

Provider lookups wait for an explicit PriceLens action. Merely opening or scrolling a marketplace page does not start comparison traffic.

Variant-aware

Storage, RAM, screen size, pack count, product edition, bundles and model generations can hard-reject a candidate before fuzzy matching.

Landed-cost aware

Unknown shipping is never silently converted to zero. Cross-border offers stay out of the headline ranking when import cost is unresolved.
