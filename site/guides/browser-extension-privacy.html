Privacy in a comparison extension

A browser extension can see page context, so request timing and data boundaries matter.

Consent first

PriceLens requires comparison consent before activating its supported-page workflow.

Lookup on demand

Safe extraction can happen locally, but provider lookup waits for an explicit lens/report action.

Secrets stay server-side

Marketplace Client Secrets and provider OAuth tokens never belong in the extension bundle.

Minimal diagnostics

Operational metrics focus on counts, states and latency rather than persistent product or user identifiers.
