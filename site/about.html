About PriceLens

PriceLens is an independent browser-extension project being developed in Germany. The goal is to help a user understand whether the same product and exact variant is available elsewhere at a meaningfully better total price.

The difficult part is not displaying prices. It is proving that two listings describe the same product, preserving condition differences, and being honest when shipping, customs or product identity is incomplete.

Current scope

The early MVP focuses on eBay.de item pages and a user-triggered comparison flow. Safe extraction happens locally first. Backend provider requests happen only after explicit user action.

Provider policy

PriceLens does not assume that a public website may be scraped and republished without restriction. Production integrations are enabled only when an official API, publisher programme or other permitted data path is documented.

Open development

The PriceLens-owned codebase is maintained in a public GitHub repository under the MIT license. Third-party code and licenses are tracked separately.
